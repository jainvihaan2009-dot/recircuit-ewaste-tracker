# recircuit-ewaste-tracker
An open-source platform for coordinating e-waste collection drives, tracking disposal metrics, and managing awareness campaigns in partnership with YI/CII.

The Goal:To collect 1 ton of e-waste in collaboration with Young Indians (YI) and CII.

How to Contribute: Open an issue to report a collection point or suggest a new recycling partner.

Impact:We are targeting specific categories like old laptops, batteries, and PCB boards to maximize resource recovery.
